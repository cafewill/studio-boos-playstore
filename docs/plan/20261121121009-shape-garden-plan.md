# 🗒 모양 정원 구현 계획

## 📖 개요

[참고 활동 리뷰](../review/20261121121009-shape-garden-review.md)를 입력으로 `contents/shape-garden/`에 자체 모양 식별 활동을 만든다. 대상은 3–5세 설계 가설이다.

## 🧩 주요 내용

### 🧩 범위와 화면

시작(시각적 모양 시범·이어서 가꾸기) → 6개 모양 찾기 → 정답 후 꽃 피우기 → 완료 → 새 정원·목록. 오답은 상태를 유지하고 힌트를 안내한다. 일시정지·탭 이탈·재개·새로고침 후 이어하기를 지원한다. 제한 시간·게임 오버·계정·광고·결제·외부 요청은 제외한다.

### 🗂 파일·저장

| 파일 | 역할 |
|---|---|
| `src/activity.js` | 시드·문항·정답·진행·중단·저장 검증 |
| `src/main.js` | 화면·입력·자체 SVG·사운드·보호자 대화상자 |
| `src/storage.js` | 저장 차단·손상 대응, 해당 키만 삭제 |
| `index.html`, `style.css` | 의미 있는 DOM·커스텀 버튼·반응형 |

저장 키는 `shape-garden:v1:session`, `shape-garden:v1:sound`다. 개인 식별 정보·실수 수·시간을 저장하지 않는다. 저장된 문항을 신뢰하지 않고 시드로 재생성하여 검사한다. 보호자 화면에서 대상 범위를 안내하고 두 번 확인 후 해당 키만 삭제한다. 이 확인은 법적 동의·인증이 아니다.

### 🎨 디자인·이름·문구

- 배경 `#F5F9F2`, 표면 `#FFFEF9`, 본문 `#243C36`, 주요 행동 `#28644E`.
- 모양 보조색 `#71966A`, `#C27F5D`, `#5F8FA6`; 색이 달라도 모양만 보고 판단 가능하게 한다.
- 자체 이름 ‘모양 정원’, 주요 행동 ‘정원 가꾸기’, 도움 ‘모서리와 둥근 곳을 살펴보고 다시 골라 볼까요?’, 중단 ‘잠깐 쉬기’.
- Fascinating 포인트: 같은 모양을 찾은 결과로 정원에 꽃 한 송이가 생긴다. 소리·움직임 없이도 진행과 완료를 이해할 수 있다.

### ✨ 커스텀·반응형·접근성

실제 버튼에 자체 스타일을 적용하고 기본 SELECT 등 폼을 나열하지 않는다. 목표 모양은 SVG와 이름으로, 선택지는 접근 가능한 실제 버튼으로 제공한다. 새 질문·정답·완료의 포커스를 관리하고 대화상자는 닫힐 때 보호자 버튼으로 포커스를 돌린다. 모바일부터 데스크톱까지 배치를 변경하며 모션 감소를 지원한다.

### 🛡 권리 근거

원작 코드·그래픽·브랜드·화면·문항·음원은 미사용이다. 기하 모양·SVG 식물·문항 생성·문구·합성음은 자체 작성하며 상세 기록은 콘텐츠 README에 둔다. 공개 전 가칭의 명칭·상표·유사 표현 검토는 미완료다.
