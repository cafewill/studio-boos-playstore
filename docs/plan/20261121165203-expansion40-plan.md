# 🗒 콘텐츠 100개 확장 계획

## 📖 개요

현재 60개 MVP에 40개를 추가하여 콘텐츠 가능성을 넓힌다. 수량 증가는 고유 메커닉 100개나 완성품 100개를 뜻하지 않는다. 기존 322개 조사 판정을 보존하며 조건부 후보의 좁은 범위 검토를 별도 배치로 기록한다.

## 🧩 주요 내용

| 배치 | 정의 수 | 엔진 | 범위 |
|---|---|---|---|
| 기존 | 60 | 7 | 기존 수·미술·조립·코딩·감정·시간·소리 |
| 확장 | 40 | 신규 3 | 낱말 10·생활 순서 10·공간 창작 20 |
| 합계 | 100 | 10 | 설정·주제 변형 포함, 최종 완료 별도 |

### 🔄 구현·검증 순서

1. 후보별 출처·기존 조건·제외 요소·좁은 구현 범위를 배치 리뷰와 정의에 기록한다.
2. 순수 엔진 words·routine·scene을 공통 상태·저장 계약에 등록한다. 기존 엔진의 의미와 저장 버전은 변경하지 않는다.
3. 그림책·순서 작업대·소품 공간의 표시를 공통 어댑터로 구성한다. 입력은 동일 버튼·키보드·쉬기 계약을 사용한다.
4. 레지스트리에서 생성하고 전체 정의·로직·복원·저장 격리·문서와 신규 엔진의 비정상 입력을 검사한다.
5. 브라우저·실제 Android·긴 문구·터치·보조기술·아동 관찰은 별도 실행해 기록한다. 미실행은 완료로 표시하지 않는다.

### 🖼 소개·그림 반복 개선

100개 정의의 소개를 실제 단어·생활 흐름·소품·조작에 맞춰 작성한다. 카드·시작 화면은 실제 설정에서 그림을 구성하고, 미술 17개는 다른 윤곽의 안내선을 SVG·Canvas에서 공유한다. 기존 공통 꽃 그림은 포털의 직접 가꾸는 정원에 한정한다. 이 변경은 주제별 표현 개선이며 규칙 엔진 100개나 실제 브라우저 검증 완료를 의미하지 않는다.

### 🎨 정서·다양성·권리

낱말은 하늘색, 순서는 초록색, 공간은 보라색의 짙은 강조색을 사용하며 밝은 표면과 본문 대비를 유지한다. 발달 효과는 단정하지 않는다. 이름은 친숙한 일상·자연 어휘로 구성하고 실패 벌점·속도 압박·외모 우열을 넣지 않는다.

새 엔진의 장면은 서로 다르게 구성하지만 같은 엔진 안의 테마 변형도 포함한다. 제목·테마 변형을 고유 놀이 메커닉으로 집계하지 않는다. 원작 UI·교재·캐릭터를 복제하지 않으며 이름·상표 공개 검토는 남아 있다.
