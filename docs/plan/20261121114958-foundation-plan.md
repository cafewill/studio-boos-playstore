# 🗒 아동 콘텐츠 스튜디오 초기 계획

## 📖 개요

참고 프로젝트의 문서 운영 방식을 바탕으로 Google Play 스토어 아동 콘텐츠 재구현 스튜디오를 구성한다. 초기 지침·가이드 구성을 완료했고 후속 지시에 따라 TOP 100 조사와 첫 활동 구현을 진행했다.

| 단계 | 산출물 | 상태·완료 기준 |
|---|---|---|
| 1. 참조 검토 | 참고 프로젝트 리뷰 | 완료: 채택·수정 근거 기록 |
| 2. 협업·프로젝트 기준 | AGENTS·README·GLANCE | 완료: 현재와 향후 구조 구분 |
| 3. 도메인 가이드 | 조사·구현·아동 UX 문서 | 완료: 템플릿·검증 기준 제공 |
| 4. 문서 미리보기 | MD·HTML 짝 | 전체 변환·내부 링크 점검으로 확인 |
| 5. 후보 조사 | 대한민국 FAMILY 인기 무료 TOP 100 | 완료: 100개 확보·96개 상세 파싱·4개 미확인 기록 |
| 6. 첫 콘텐츠 | 모양 정원 리뷰·계획·독립 웹 활동·검증 결과 | 구현·로직 검증 완료, 브라우저 검증 대기 |

### 🧩 후속 범위 설정

다음 작업에서는 대상 연령, 선호 활동(퍼즐·수 개념·언어·창작·이야기), 한글 읽기 수준, 주 사용 기기를 우선 파악한다. 답이 없으면 후보 비교 시 가정을 명시하고 구체적 앱명·순위는 실제 조사 후 기록한다.

첫 MVP는 한 가지 핵심 활동과 명확한 종료 조건으로 제한한다. 네이티브 포장·스토어 제출·결제·광고·계정·대규모 포털은 별도 범위다. Git 저장소 초기화와 `origin` 설정은 오빠가 완료했다. 최초 커밋·푸시는 `main`에 완료했으며 후속 변경은 feature 브랜치에서 관리한다.

현재 후속 구현은 [60개 배치 계획](20261121140822-batch60-plan.md)이 정본이다. 초기 1개 이후 60개 MVP 정의·7개 공통 엔진으로 확장했으며 실제 브라우저·기기 검증은 대기 중이다.
