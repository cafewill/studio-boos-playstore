# 🗒 아동 콘텐츠 스튜디오 초기 계획

## 📖 개요

참고 프로젝트의 문서 운영 방식을 바탕으로 Google Play 스토어 아동 콘텐츠 재구현 스튜디오를 구성한다. 현재 요청 범위는 지침·가이드 구성이며 실제 콘텐츠 구현은 다음 작업이다.

## 🧩 주요 내용

| 단계 | 산출물 | 상태·완료 기준 |
|---|---|---|
| 1. 참조 검토 | 참고 프로젝트 리뷰 | 완료: 채택·수정 근거 기록 |
| 2. 협업·프로젝트 기준 | AGENTS·README·GLANCE | 완료: 현재와 향후 구조 구분 |
| 3. 도메인 가이드 | 조사·구현·아동 UX 문서 | 완료: 템플릿·검증 기준 제공 |
| 4. 문서 미리보기 | MD·HTML 짝 | 전체 변환·내부 링크 점검으로 확인 |
| 5. 후보 조사 | 연령·유형별 Google Play 스토어 후보 3–5개 | 미착수: 다음 콘텐츠 작업에서 진행 |
| 6. 첫 콘텐츠 | 리뷰·계획·독립 웹 활동·검증 결과 | 미착수: 대상과 MVP 범위 결정 후 구현 |

### 🧩 후속 범위 설정

다음 작업에서는 대상 연령, 선호 활동(퍼즐·수 개념·언어·창작·이야기), 한글 읽기 수준, 주 사용 기기를 우선 파악한다. 답이 없으면 후보 비교 시 가정을 명시하고 구체적 앱명·순위는 실제 조사 후 기록한다.

첫 MVP는 한 가지 핵심 활동과 명확한 종료 조건으로 제한한다. 네이티브 포장·스토어 제출·결제·광고·계정·대규모 포털은 별도 범위다. Git 저장소 초기화와 `origin` 설정은 오빠가 완료했다. 최초 커밋·푸시는 오빠의 후속 지시에 따라 `main`에 직접 진행한다.

## 📌 요약 정보

초기 구성 완료 기준은 문서 탐색 경로, 조사·계획 템플릿, 아동 UX·안전·실제 입력 검증 기준, 생성 HTML과 유효한 내부 문서 링크다.
