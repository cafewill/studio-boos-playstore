# 🔍 모양 정원 참고 활동 리뷰

## 📖 개요

대한민국 FAMILY TOP_FREE 응답 순번 47의 [핑크퐁 모양 색깔](https://play.google.com/store/apps/details?id=kr.co.smartstudy.shapescolors_android_googlemarket&hl=ko&gl=KR), 순번 63의 [RV AppStudios 유아 활동 모음](https://play.google.com/store/apps/details?id=com.rvappstudios.baby.toddler.kids.games.learning.activity&hl=ko&gl=KR)을 조사했다. 출처별 개발사·버전·평점·다운로드·광고·결제·확인 시각은 [수집 스냅샷](../../data/store/20261121121009-family-top-free-kr.json)에 있다.

공식 설명은 모양·색·수량 등의 놀이학습 활동을 제시한다. 직접 설치·플레이·스크린샷 비교는 하지 않았으므로 원작 UI·실제 난이도·오프라인 동작을 관찰 사실로 쓰지 않는다. 3–5세는 자체 활동의 설계 대상이며 검증된 연령 적합성이나 원작의 비공개 신고 연령이 아니다.

## 🧩 주요 내용

### 🔄 추상 활동과 자체 목표

시각 목표 제시 → 같은 기하 모양 선택 → 일치 여부 안내 → 다음 목표를 고르는 일반 활동만 참고한다. 학습 목표는 동그라미·네모·세모의 형태를 보고 일치하는 모양을 고르는 것이다. 색은 보조 장식이며 정답 단서가 되지 않게 목표와 선택지의 색을 분리한다.

6문항에 각 모양을 두 번씩 배치하고 시드로 제시·선택 위치를 섞는다. 오답은 감점 없이 다시 고르고 정답 후 다음 문항은 아이가 버튼으로 진행한다. 최종 정원은 모든 아이가 같은 6송이 꽃으로 완료한다. 시간·실수 수·우열을 보여주지 않는다.

### 🎨 컬러·용어·Fascinating

크림에 가까운 흰 표면과 연한 녹색 배경, 짙은 녹색 글자·버튼을 사용한다. 정답을 찾을 때 자체 기하 꽃 하나가 조용히 피며 모션 감소 환경에서는 애니메이션 없이 상태만 변한다. 정서 안정은 설계 목표이며 색의 발달 효과를 주장하지 않는다.

자체 이름 ‘모양 정원’, 완료 ‘모양 정원이 활짝 피었어요’, 오답 ‘모서리와 둥근 곳을 살펴보고 다시 골라 볼까요?’를 사용한다. 존중하는 피드백과 쉬기·돌아가기를 제공한다.

### 🛡 독립 표현·권리

원작의 놀이공원·브랜드·등장인물·영상·음원·코드·문항 배열·화면 구성은 사용하지 않는다. 구현 코드는 추상 활동과 자체 계획을 기준으로 직접 작성하고 SVG 꽃·도형은 자체 기하 구성이다. 효과음도 직접 합성한다. 코드·에셋·문구 제작 기록은 콘텐츠 README에 둔다.

가칭의 상표·명칭 충돌은 공개 전 별도 검토 대상으로 남긴다. 일반적인 모양 선택을 참고했다는 이유만으로 모든 권리 문제가 없다고 단정하지 않는다.
