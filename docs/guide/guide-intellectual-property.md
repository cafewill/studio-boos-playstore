# 🛡 독립 재구현·저작권·지식재산권 가이드

## 📖 개요

모든 조사·선정·리뷰·계획·구현·수정·검증·공개에서 지식재산권 검토를 필수 적용한다. 프로젝트에서 클론은 참고 활동을 분석한 후 독립적인 콘텐츠로 구현한다는 뜻이다. 원작과 혼동될 복제품을 만들지 않는다. 내부 검토를 법적 무위험 보증이나 권리자의 허락으로 표현하지 않는다.

## 🧩 주요 내용

### 🔄 독립 구현 절차

1. 공식 공개 자료의 출처·확인일·관찰 범위를 기록한다. 원작의 이름은 출처를 식별할 분석 문서에서만 필요한 범위로 언급한다.
2. 참고할 일반적인 활동 아이디어와 사용하지 않을 구체적 표현을 분리한다. “같은 모양 찾기”처럼 추상적 요구사항을 자체 문장으로 작성한다.
3. 자체 이름·주제·레이아웃·색상 체계·캐릭터·문항·레벨·음원을 새로 설계하고, 원작 표현과의 차이 및 제작 근거를 계획에 남긴다.
4. 원작 코드·리소스를 추출·디컴파일·트레이싱하거나 유료 콘텐츠·접근 제한을 우회하지 않는다. 화면·문항·레벨의 배열과 진행 순서를 그대로 옮기지 않는다.
5. 구현과 홍보 화면을 검토하고, 출처·허락·라이선스가 불명확한 요소는 사용하지 않거나 자체 제작물로 교체한다. 권리 확인이 필요한 해당 요소만 보류하고 독립 구현 가능한 작업은 계속한다.

### 🗂 대상별 기준

| 대상 | 적용 기준 |
|---|---|
| 이름·상표·캐릭터 | 자체 명칭과 외형 사용. 유사한 발음·로고·실루엣·제휴 암시로 혼동을 유발하지 않음 |
| 화면·그래픽 | 스크린샷·스프라이트·아이콘·일러스트 추출 금지. 색만 바꾸거나 위치만 옮긴 복제·트레이싱 금지 |
| 문구·문항·스토리 | 설명·대사·교재·퀴즈·퍼즐·레벨 데이터 직접 작성. 번역·일부 수정만으로 자체 창작물로 간주하지 않음 |
| 음악·음성·영상 | 자체 합성·녹음·창작 또는 사용 권한이 확인된 자료만 사용. 유명 멜로디·방송 대사·원작 효과음·동요 편곡도 개별 확인 |
| 폰트·라이브러리 | 무료 배포와 사용 허락을 구분. 라이선스 파일·저작권 표시·재배포 조건 유지 |
| 오픈소스 코드 | 공개되어 있다는 이유만으로 복사하지 않음. 라이선스·고지·소스 제공 의무 등 조건 확인 후 호환되는 범위에서 사용 |
| AI 제작 자료 | 원작 캐릭터·특정 화면의 복제를 지시하지 않음. 생성 경로·약관·유사성·표시 의무 검토. AI 생성만으로 권리 확보를 단정하지 않음 |
| 조사 데이터 | 순위·식별자·평점 등 확인 가능한 사실을 기록하고 설명문은 자체 요약. 원문·이미지 대량 재배포를 조사 명목으로 하지 않음 |
| 사용자 창작 | 외부 업로드·공유는 기본 범위에서 제외. 도입 시 이용허락·신고·삭제 정책 별도 설계 |

원작과 비교할 고정 차이 개수나 유사도 퍼센트로 안전을 판정하지 않는다. 일반 규칙의 참고 여부와 별도로 코드·그래픽·표현의 조합·상표·특허 등 다른 권리도 문제될 수 있으므로 독창적인 화면과 흐름을 설계한다.

### 📋 권리·출처 기록

콘텐츠 README에 다음 표를 유지한다. 전부 직접 작성한 경우에도 코드·도형·문구·문항·사운드별 자체 제작 근거를 기재한다.

| 파일·요소 | 제작자·출처 URL | 권리 근거·라이선스·버전 | 수정·고지·재배포 조건 | 확인일·상태 |
|---|---|---|---|---|
| 예: 자체 SVG 도형 | 프로젝트 자체 제작 | 직접 작성한 기하 도형 | 외부 도안 미사용 | YYYY-MM-DD·확인 |

외부 자료를 쓰면 라이선스 원문 또는 허락 증빙의 위치도 기록한다. 출처 표기만으로 사용 허락을 대신하지 않으며, 로컬·무료·비상업·교육 목적이라는 이유만으로 복제를 허용하지 않는다. 실제 사용자 데이터나 불필요한 계정·인증정보를 증빙에 포함하지 않는다.

### ✅ 검증·공개 기준

- 리뷰: IP 의존도와 일반 활동·구체적 표현의 경계를 기록했는가?
- 계획: 자체 명칭·테마·화면·문항·에셋 대체안이 구체적인가?
- 구현: 원작 파일·브랜드·대사·문항·레벨·UI 트레이싱이 포함되지 않았는가?
- 의존성: 에셋·폰트·음원·소스의 권리 근거와 필수 고지가 있는가?
- 공개: 이름·아이콘·스크린샷·소개 문구가 원작 또는 공식 제휴물과 혼동되지 않는가?
- 보류: 미확인 권리·허락 조건을 명시하고 해당 요소를 제외·교체했는가?

공개·상용화 전에 이름·상표·유사 표현·특허 등 남은 쟁점을 재검토한다. 권리자 허락이 필요한 표현을 그대로 사용할 사안이나 판단이 불분명한 쟁점은 적절한 권리 확인·전문 검토 후 처리한다.
