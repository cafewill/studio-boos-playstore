# 🔍 Google Play 스토어 아동 콘텐츠 조사·리뷰

## 📖 개요

인기 순위뿐 아니라 연령 적합성·놀이의 질·학습 목표·자체 구현 가능성을 기준으로 후보를 선정한다. 대한민국 Google Play 스토어(`gl=KR`, `hl=ko`)를 기본으로 하며 게임·교육·어린이 관련 앱과 편집 추천을 함께 살핀다.

## 🧩 주요 내용

### 🔄 조사 절차

1. 대상 연령과 활동 유형을 정한다. 미정이면 연령대별 후보를 비교하고 가정을 명시한다.
2. 공식 Google Play 스토어 상세 페이지(`play.google.com/store/apps/details?id={packageId}`)와 개발사 자료에서 TOP 100을 최소 출발점으로 조사하고 적합 후보가 부족하면 차트 깊이·카테고리·무료/유료/최고 매출을 확대한다. 대한민국을 유지하고 실제 반환 수·미확인 차트·원차트별 응답 순서·기기 UI 검증 여부를 기록한다. 요청 개수나 여러 차트를 합친 목록을 공식 통합 순위로 표시하지 않는다.
3. 패키지 ID 기준 중복을 제거한 고유 앱 전체를 적합 후보·조건부·보류·제외로 분류한다. 기존 결과를 보존하고 확장으로 새로 찾은 후보와 구분한다. 수를 늘리려고 적합성 기준을 완화하지 않는다. 중복 제거·파싱 실패·아동 범위 밖 앱을 기록하고 미확인 값을 임의로 보충하지 않는다.
4. 적합 앱 수와 서로 겹치지 않는 활동 유형·구현 콘텐츠 수를 구분한다. 색칠 앱 여러 개를 신규 콘텐츠 여러 개로 자동 집계하지 않는다.
5. 출처와 직접 관찰·개발사 주장·구현 추정을 분리하여 리뷰한다.
6. 핵심 활동 1개, 학습 목표 최대 1–2개로 MVP를 좁히고 계획에 연결한다.

### 🗂 조사 항목

| 항목 | 기록 기준 |
|---|---|
| 식별 | 원작명·개발사·패키지 ID(applicationId)·국가·공식 URL |
| 시점 | KST 조사 시각·앱 버전·업데이트일(확인 가능 시) |
| 노출 | 인기 무료·인기 유료·최고 매출 등 실제 표시된 차트명·카테고리·순위·조회 범위, 미노출은 미확인 |
| 연령 | 스토어 콘텐츠 등급, 공식 자료에서 확인한 대상 연령, 프로젝트 권장 연령을 구분 |
| 평가 | 평점과 평가 수를 구분, 다운로드 구간은 상세 페이지 공개 표시 그대로 기록하고 정확한 설치 수로 환산하지 않음 |
| 이용 | 가격·구독·인앱 결제·광고·오프라인 지원, 확인 가능한 범위만 |
| 관찰 | 직접 실행/공식 영상/스크린샷/설명 중 어떤 자료로 판단했는지 |
| 가치 | 핵심 놀이, 학습 목표, 읽기·운동 조작 요구 수준 |
| 정서·표현 | 컬러 컨셉·용어·이름·피드백의 연령 적합성, 안정감·존중·자율성, 자체 구현 대체안 |

선생님 추천(Teacher Approved) 표시는 실제 노출된 경우에만 기록하며 Families 정책 준수와 같은 의미로 쓰지 않는다. 개발사의 Play Console 대상 연령은 공개 정보가 아닐 수 있으므로 미확인 값을 추정하지 않는다.

순위·가격·정책은 조사 시점 정보다. 서로 다른 국가·날짜의 차트를 합쳐 동일 순위처럼 쓰지 않는다. 스토어의 낮은 연령 등급만으로 아동 교육 적합성을 판단하지 않는다.

### ✅ 후보 선정

| 기준 | 우선 방향 |
|---|---|
| 활동 | 1–3회 조작으로 핵심 경험 파악 가능 |
| 교육 | 수 세기·분류·패턴·음운·공간 인지 등 관찰 가능한 목표 |
| 구현 | 로컬 웹 MVP로 핵심 활동 검증 가능 |
| 표현 | 자체 캐릭터·문항·음원·배경으로 대체 가능 |
| 정서 | 아이를 존중하는 이름·문구와 식별하기 편한 색상, 공감·탐색·자율적 중단을 지원할 수 있는 활동 |
| 제외 | 계정·서버·외부 채팅·카메라가 핵심이거나 유명 IP 재현에 의존 |

### 🗒 리뷰 템플릿

`docs/review/{TS}-{slug}-review.md`에 공통 작성일·작성자·마침 문구를 포함하고 아래 항목을 채운다.

```text
# 🔍 {자체 콘텐츠명} 참고 콘텐츠 리뷰
## 📖 개요
- 원작명 / 개발사 / 패키지 ID(applicationId) / 국가 / URL / 조사 시각
- 버전 / 가격 / 평점·평가 수 / 차트·순위 / 확인 불가 항목
- 정보 확인 방식과 직접 체험 여부
- 스토어 콘텐츠 등급 / 공식 자료의 대상 연령 / 프로젝트 대상 연령과 근거
## 🧩 주요 내용
### 🔄 핵심 활동
- 행동 → 피드백 → 다음 행동, 1회 활동의 종료 조건
### 🧠 놀이·학습 목표
- 목표 / 선행 능력 / 아이가 할 행동 / 확인 방법
### 🎨 화면·입력·접근성
- 화면 전환 / 읽기 의존도 / 터치 / 소리 없이 이용 가능 여부
- 주요 행동 / 자체 커스텀 컴포넌트 방향 / Fascinating 발견 포인트 / 반응형·접근성 위험
### 🎨 컬러·용어·네이밍
- 목표 정서 경험 / 원작 표현의 관찰 근거 / 자체 팔레트 역할·HEX·선정 이유
- 자체 이름·의미 / 시작·정답·오답·힌트·종료 문구 / 비교·압박·고정관념의 대체안
### 🛡 보호자·데이터
- 원작 관찰 내용 / 자체 구현에서 제외·변경할 내용
### 🛡 저작권·지식재산권
- IP 의존도 / 참고할 추상 활동 / 제외할 구체적 표현 / 자체 대체안 / 미확인 권리
### 🧩 MVP와 자체 표현
- 포함 / 제외 / 자체 테마·문항·에셋 / 출처·라이선스
### ✅ 수용 기준
- 정상 입력 / 오답 / 힌트 / 중단·재개 / 종료 / 데이터 삭제
## 📌 요약 정보
- 난이도 / 위험 / 미확정 사항 / 연결 계획
```

### 🎨 재구현 경계

[저작권·지식재산권 가이드](guide-intellectual-property.md)를 모든 조사·선정·리뷰에 필수 적용한다. IP 의존도와 일반 활동·구체적 표현의 경계를 기록한다.

장르의 규칙과 일반적인 활동 구조를 참고하고 이름·로고·캐릭터·UI 구성·아이콘·대사·음원·문항·레벨 데이터는 자체 제작한다. 원작 파일 추출·스크린샷 재사용·화면 트레이싱은 하지 않는다. 분석 문서의 원작명 언급과 구현물의 브랜드는 분리한다.

외부 에셋은 출처 URL·저작자·라이선스·수정 여부·고지 조건을 콘텐츠 README에 기록한다. 교육 문항과 삽화도 같은 기준을 적용한다.
