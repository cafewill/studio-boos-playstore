# 📚 아동 콘텐츠 개발 가이드

## 📖 개요

Google Play 스토어 아동용 콘텐츠의 조사부터 독립 웹 콘텐츠 구현·검증까지 적용할 기준이다. 전체 현황의 정본은 [GLANCE.md](../../GLANCE.md)다.

## 🧩 주요 내용

| 가이드 | 적용 내용 |
|---|---|
| [조사·리뷰](guide-content-review.md) | 원작 확인, 후보 비교, 리뷰 템플릿, 자체 표현 |
| [Fascinating UI](guide-ui-design.md) | 커스텀 컴포넌트·절제된 발견 경험·접근성·반응형·검증 |
| [구현·검증](guide-content-build.md) | 구조, 구현 계획 템플릿, 실행, 완료 조건 |
| [아동 UX·안전](guide-child-safety.md) | 연령별 인터랙션, 정서 함양을 고려한 컬러·용어·네이밍, 학습 피드백, 보호자 영역, 데이터 |

리뷰와 계획은 [리뷰 목차](../review/review.md)와 [계획 목차](../plan/plan.md)에서 관리한다. 새 가이드를 추가하면 이 목록과 루트 문서 색인을 함께 갱신한다.

## 📌 요약 정보

MD가 원본이며 `python3 docs/tools/md_to_html.py --all`로 같은 이름의 HTML을 생성한다. 초기 구성 이후 실제 콘텐츠 구현은 콘텐츠별 리뷰·계획에 따라 진행한다.
