# 🧪 콘텐츠 100개 확장 검증

## 📖 개요

기존 60개와 신규 40개를 활성 레지스트리 전체로 검증했다. 원본 322개 조사 및 적합 60·조건부 178·보류 57·제외 27 판정을 보존했다. 신규 40개는 조건부 앱에서 범위를 제한한 독립 프로토타입이며 원작 전체의 구현 완료를 의미하지 않는다.

확인 명령은 `node tools/check-all.mjs`다. 도구 경로의 batch60은 기존 호환 이름이며 대상은 활성 레지스트리 100개 전체다. 브라우저 도구에도 신규 세 유형의 완료 입력 경로를 추가했으나 실제 실행 성공은 기록하지 않는다.

### ⚠️ 미실행·제한

`npm start` 실행은 socket.bind에서 `PermissionError: [Errno 1] Operation not permitted`로 종료됐다. 서버 구동·접속 성공으로 표시하지 않는다. 실제 브라우저 렌더·터치·기기별 그림 문자·스크린리더·실제 Android·아동 관찰·흥미 지속은 미검증이다. 정적 HTML 생성 검사는 화면 품질을 보장하지 않는다. 미술 안내선은 SVG와 Canvas가 같은 경로를 사용하도록 구현했지만 실제 Canvas 렌더·저장 획과의 시각적 겹침은 브라우저 검증이 남아 있다.
