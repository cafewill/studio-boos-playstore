# 🌱 무지개 그림 한 장

## 📖 개요

무지개 그림 한 장에서 선과 점, 색을 자유롭게 골라 나만의 그림을 만들어요. 3–5세는 자체 설계 가설이며 실제 아동 적합성 검증을 뜻하지 않는다.

## 🧩 주요 내용

- 구조: 공통 셸·drawing 엔진·free 활동 설정을 사용한다. 이 README와 진입 파일은 생성 파일이며 정본은 data/implementation/batch60.json이다.
- 조작: 실제 버튼을 클릭·탭하거나 Tab·Enter·Space로 조작한다. 그리기는 포인터 드로잉과 위치 버튼 대안을 함께 제공한다.
- 진행: 시작 → 활동 → 발견 피드백 → 완료. 시간·실수 벌점·우열 경쟁 없이 쉬기·이어서 하기·다시 하기를 제공한다.
- 저장: rainbow-page:v2:session, rainbow-page:v2:sound. 저장 차단·손상·버전 불일치에 대응하며 다른 콘텐츠 키를 삭제하지 않는다.
- 삭제: 보호자 대화상자에서 해당 활동의 기록만 두 번 확인 후 삭제한다. 법적 동의·인증 기능이 아니다.
- 소리: 기본 꺼짐, 사용자 동작으로 활성화하며 시각 정보만으로 완료할 수 있다.
- 실행: 루트에서 python3 -m http.server 7904 --bind 127.0.0.1 후 /contents/rainbow-page/. ?seed=7로 재현한다.
- 검증: node tools/content/check.mjs 및 node tools/logic/batch60.mjs. 브라우저·실제 기기·아동 관찰의 실행 여부는 배치 검증 기록을 따른다.
